## 1. Комплексный анализ клиентской базы и истории покупок
📁 Папка: [`customer-base-analysis`](./customer-base-analysis)

Итоговый проект курса «Data Analyst. Junior»: от подготовки данных до рекомендаций для маркетинга.

**Данные:** 15 748 клиентов в основной выборке, 786 260 покупок, 104 989 уникальных ID.

**Что сделано:**
- загрузка данных из SQLite (SQL), контроль качества, очистка названий товаров;
- расчёт поведенческих признаков клиентов;
- классификация (Logistic Regression, Random Forest, Gradient Boosting);
- сегментация клиентов методом K-Means (6 сегментов);
- анализ скидочного поведения по сегментам;
- propensity-модель покупки товара «брюки мужские Demix»;
- дизайн A/B-теста и проверка сопоставимости групп (χ²-тест).

**Ключевые результаты:**
- выделено 6 поведенческих сегментов: самый крупный содержит 5 369 клиентов (34,09%), сверхактивный сегмент — 53 клиента (≈95 покупок на клиента);
- кластер 1 наиболее чувствителен к скидкам (62,23% покупок со скидкой), кластер 2 — наименее (16,77%);
- целевая аудитория — 1 913 клиентов, из них 58 ранее покупали целевой товар (3,03%);
- propensity-модель: ROC-AUC = 0,765; Top 10% рейтинга (191 клиент) покрывает 29,31% известных покупателей;
- до кампании группы A и B сопоставимы: 3,18% против 2,88% (χ² = 0,063, p = 0,802).

**Бизнес-рекомендации:**
- запустить ограниченный пилот персонализированной коммуникации на Top 10% propensity-рейтинга;
- сохранять случайное A/B-разделение и заранее фиксировать основную метрику;
- использовать разные CRM-сценарии: скидки для чувствительных к ним клиентов, удержание для сверхактивных/VIP;
- оценивать не только конверсию, но и выручку на клиента, средний чек и маржу;
- переобучить модель после накопления новых данных.

**Ограничения:** качество классификации невысокое (лучший F1 = 0,51); данные A/B-теста до кампании не измеряют эффект кампании.

**Материалы:** Jupyter Notebook с кодом, аналитический отчёт (PDF) и презентация (PDF) лежат в папке проекта.

## 2. Анализ сайта «СберАвтоподписка»
📁 Папка: [`sberautopodpiska-site-analysis`](./sberautopodpiska-site-analysis)

Разведочный анализ данных сайта (≈1,86 млн визитов): конверсия в целевые действия, источники трафика, устройства, география, время визита и проверка статистических гипотез.

**Что сделано:**
- проверка пропусков, дубликатов и ключей, очистка данных, создание целевого признака;
- расчёт Conversion Rate (CR) по устройствам, источникам, кампаниям, регионам, часам и дням недели;
- проверка трёх гипотез (Z-тест для двух долей), доверительные интервалы, поправка на множественные сравнения;
- анализ спроса на автомобили и эффективности трафика из социальных сетей.

**Ключевые результаты:**
- общий CR сайта ≈ 2,70%;
- повторные визиты конвертируются лучше первых: 3,71% против 2,35%;
- органический трафик: CR 4,04%, платный: 2,19% (p < 0,001);
- desktop: CR 3,14%, mobile: 2,60% (p < 0,001), при этом мобильный трафик значительно больше по объёму;
- Москва, МО и Санкт-Петербург: CR 2,80%, остальные регионы: 2,55% (p < 0,001);
- лучший период — день (12:00–17:59), CR ≈ 3,00%; лучший день недели — понедельник (3,15%);
- социальные сети: CR 1,47% против 2,92% у остального трафика.

**Рекомендации:**
- оценивать каналы одновременно по объёму трафика, числу конверсий и CR, а также по стоимости привлечения;
- улучшить мобильную версию сайта (скорость, формы, путь до целевого действия);
- анализировать новых и возвращающихся пользователей отдельно;
- перед перераспределением бюджета проверять каждый социальный источник отдельно.
